LogSift
High-performance concurrent CLI log analyzer — parses and summarizes web access logs, surfacing traffic metrics, status codes, and top paths.

Wanted to see how fast a log analyzer could go with nothing but the standard library. Fanning the work across concurrent workers chews through a 50 MB / 500k-line file in about 200 ms — zero external dependencies, just Go's runtime doing the heavy lifting.

2D Navier-Stokes Solver
Computational fluid dynamics simulation of 2D incompressible viscous flow.

Started this to actually understand the math behind fluid simulation instead of just reading about it. Writing the projection method from scratch in C++ forces you to confront every boundary condition and stability assumption.

Discord LLM Bot
Voice bot that listens in a Discord channel, plays music, and talks back using OpenAI.

Wanted a hands-free way to hang out in voice with friends — ask for a song, ask a question, get a spoken answer. Built around Whisper for transcription, OpenAI for responses, and yt-dlp for audio, deployed on EC2.
